# SFKGames 2026
## Make Your First Open Source Contribution

Want to make your first contribution to an open source project? Start here!

### Your challenge

Add yourself to `participants.json` by answering:

* **Name:** Your name or GitHub username
* **Favorite open-source tool:** A tool, project, or technology you use or like
* **Why:** One short sentence explaining why

### How to play

1. Fork this repository
2. Create a new branch
3. Add your entry to `participants.json`
4. Commit your changes
5. Open a Pull Request
6. Show your PR to an SFK volunteer/staff at the FLOSSK Booth

Your PR is your proof! 🎉
